- Source theme: `Bibata-Modern-Ice`
- Source version: `v2.0.6`
- Snapshot origin: the locally installed Hyprcursor archives at
  `~/.local/share/icons/Bibata-Modern-Ice/hyprcursors/*.hlc`

Each `.hlc` archive was extracted into a source directory containing its
original `meta.hl` and SVG frames. The cursor shapes, hotspots, overrides and
animation delays are retained. NEON changes only the color roles before
building Hyprcursor and XCursor artifacts.
